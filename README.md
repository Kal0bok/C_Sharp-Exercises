# C# Programming Fundamentals

Ar **.NET** izstrādāta konsoles lietotne, kas demonstrē C# pamatprincipus, programmas izpildes plūsmu, kolekcijas, un objektorientētās programmēšanas (OOP) pamatus.

## 🛠 Features & Concepts Covered:
- **Control Flow:** `if / else`, `switch`, safe input parsing with `int.TryParse`.
- **Collections:** `List<T>`, array iteration, LINQ functions (`Sum`, `Average`, `Where`, `Min`, `Max`).
- **OOP Basics:** Classes, properties (`get; set;`), constructors, and methods.
- **Exception Prevention:** Safe user inputs and validation.
